# AES Is Secure, Right?

**Турнир:** KubCTF · **Категория:** crypto

**Статус:** Не решено.

## Что известно

Ключ AES-128-ECB равен SHA256(PIN)[:16]. Шифротекст состоит из девяти блоков, дополнительно переставленных.

## Ход анализа

Перестановка обратима: reverse, затем rotate right на сумму цифр PIN modulo 9. В архивных опытах исчерпаны десятичные PIN длиной 1–9, начинающиеся с 2. Корректный PKCS#7 встречался случайно, но полностью печатного текста и флага не получено.

## Результат и ограничения

Флаг не найден. Обратимость перестановки не раскрывает ключ SHA256; отдельного криптоаналитического сокращения не установлено. Дальнейший диапазон без новой подсказки не проверялся.
