# RISC-V

**Турнир:** KubCTF · **Категория:** reverse

**Статус:** Решено.

## Кратко

Настоящий control flow RV32 спрятан в обработчике illegal instruction. После снятия загрузочного XOR восстановление Feistel и RC4 раскрывает UART-ключ и флаг.

## Решение

### 1. Снять загрузчик и восстановить trap-диспетчер

Загрузчик хеширует little-endian слова по смещениям 0…0xd8, затем xorshift32 (13,17,5) снимает XOR с `fw.bin[0xe0:0x40e0]`. Начало — именно 0xe0: AUIPC отсчитывается от адреса своей инструкции. Payload загружается по 0x80100000. Обработчик `mcause=2` трактует слова с младшими битами 0x0007f как вызовы функций, а 0x0000107f — как возврат через программный стек.

### 2. Обратить Feistel и получить ключ потока

Таблица dispatch по offset 0x8bc ведёт к инициализации RC4, восьми Feistel-раундам и проверке 16-байтного UART-ввода. Обратить раунды от target по offset 0x8ac. Затем пройти прямое преобразование с найденным вводом и накопить четыре 32-битных хеша. Их little-endian конкатенация — ключ RC4 для 39 байт по offset 0x884. Независимый эмулятор всей прошивки вывел флаг; изменение последнего байта ввода привело к denied.
