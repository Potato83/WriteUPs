# Curve Ball

**Турнир:** KubCTF · **Категория:** crypto

**Статус:** Решено.

## Кратко

Цепочка эллиптических кривых содержит аномальную первую кривую и гладкий порядок точки на второй. Их последовательный взлом раскрывает ключ AES.

## Решение

### 1. Раскрыть C1 атакой Smart

На C1 выполняется условие аномальности. Поднять точки в p-адическое поле, вычислить отображение через p-кратные точки и восстановить k1. Обязательно проверить `k1*G1 == P1` над исходным конечным полем.

### 2. Раскрыть C2 и расшифровать флаг

Ключ промежуточного AES-CBC — `SHA256(b"C1->C2:" + str(k1).encode())`. После расшифровки параметров C2 решить DLP по гладкому порядку G2 и проверить `k2*G2 == P2`. Финальный ключ — `SHA256((str(k1)+":"+str(k2)).encode())`. C3 для этого пути не нужна. Проверить PKCS#7 и UTF-8.
