# Mercury - Game SHOP

**Турнир:** KubCTF · **Категория:** web

**Статус:** Не решено.

## Что известно

Страницы Game SHOP раскрывают каталог, VIP-лоты, кошелёк и checkout, но завершённого пути к флагу нет.

## Ход анализа

Сохранённый ответ /internal/admin-backup — HTTP 403 с временным ограничением запросов. Встроенная строка, названная synthetic verification, не является кандидатом. Комментарии страниц с обещаниями bypass не подтверждают работоспособную уязвимость.

## Результат и ограничения

Флаг не найден. Требуется исследовать фактическое поведение обычных сценариев и права доступа; текущих заметок недостаточно для описания решения.
