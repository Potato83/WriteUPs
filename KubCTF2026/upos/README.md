# Undebuggable Piece Of Software

**Турнир:** KubCTF · **Категория:** reverse

**Статус:** Флаг турнира не найден.

## Что удалось восстановить

Проверка `FC.checkFlag` требует строку из 69 Java-символов с префиксом `MOBISEC{`. LFSR Streamer использует seed `01101000010`, tap index 2 и 12 начальных шагов; затем символы выбираются из `lotto.dat`. Точные квадратные корни и обратное преобразование ROT7 дают строку, чей SHA-256 совпадает со значением, встроенным в APK: `4193d9b72a5c4805e9a5cc739f8a8fc23b2890e13b83bb887d96f86c30654a12`.

## Результат

Полученная строка проходит локальную проверку APK, но платформа её отвергла. Это не подтверждённый флаг KubCTF; другой кандидат не найден.
