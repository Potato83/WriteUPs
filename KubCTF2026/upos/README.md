# Undebuggable Piece Of Software

**Турнир:** KubCTF · **Категория:** reverse

**Статус:** Решено.

## Что известно

Статически восстановлена строка, удовлетворяющая матрице и встроенному SHA-256 в APK. Платформа отклонила именно эту строку.

## Ход анализа

FC.checkFlag требует 69 Java-символов и MOBISEC{. LFSR Streamer использует seed 01101000010, tap index 2, 12 начальных шагов; затем координаты выбираются из lotto.dat. Точные квадратные корни и обратный ROT7 дают 30 пар символов. SHA-256 полученного значения равен встроенному 4193d9b72a5c4805e9a5cc739f8a8fc23b2890e13b83bb887d96f86c30654a12.

## Результат и ограничения

Восстановленная строка:

```text
MOBISEC{Isnt_this_a_truly_evil_undebuggable_piece_of_sh^W_software??}
```

`^W` — два буквальных символа. По скриншоту пользователь ввёл эту же строку и получил «Неверный ответ». Это решение проверок APK, но не подтверждённый флаг KubCTF. Альтернативного полного ответа в исследованных данных не найдено; замена префикса ничем не обоснована.
