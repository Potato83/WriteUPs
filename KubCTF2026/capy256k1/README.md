# capy256k1

**Турнир:** KubCTF · **Категория:** crypto

**Статус:** Решено.

## Кратко

Умножение точки не проверяет принадлежность исходной кривой. Диагностические пары на альтернативных кривых раскрывают остатки секретного скаляра, которые объединяются CRT.

## Решение

### 1. Определить кривые диагностических точек

Для каждой исходной точки вычислить `b = (y² − x³) mod p` и построить `E_b: y² = x³ + b`. Формулы умножения используют тот же коэффициент a=0, поэтому переданные точки обрабатываются и на этих кривых.

### 2. Решить малые DLP и собрать секрет

Для каждой пары `P,Q` найти `r = log_P(Q)` по модулю порядка P. Сохранённые остатки:

| b | r | Порядок P |
|---:|---:|---:|
| 2 | 3679953973 | 11799928573 |
| 3 | 26161617092 | 90287601949 |
| 4 | 223611984189 | 354690454903 |
| 5 | 8003312562 | 11472381409 |

CRT даёт `206229994785984600850531915192031064515`. Проверить все четыре умножения и передать скаляр штатной `decrypt_flag` из исходника. Независимая реализация BSGS подтвердила результат.
