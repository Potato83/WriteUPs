# Black Box

**Турнир:** KubCTF · **Категория:** forensics

**Статус:** Не решено.

## Что известно

Из образа SD и журналов MAVLink/DataFlash восстановлена часть данных для расшифрования удалённого AV_CACHE.

## Ход анализа

Удалённый /APM/SCRIPTS/AV_CACHE восстановлен с cluster 12861, длина 672, формат OpenSSL Salted__. Все три валидированные оценки центра дают geohash6 ubh09e. В логах 102–104 найдены 18 из 24 требуемых упорядоченных marks. У удалённого 00000105.BIN размер 35170895, но стартовый cluster равен нулю: обычная FAT-chain recovery его не восстанавливает.

## Результат и ограничения

Флаг не найден: не доказаны шесть недостающих marks. Строка в свободном пространстве с пометкой DRAFT flag guess не является ответом. Нужна валидированная реконструкция фрагментов DataFlash отсутствующего лога.
