# [Beginner] Honeyleaf

**Турнир:** KubCTF · **Категория:** web

**Статус:** Решено.

## Кратко

Просмотрщик квитанций принимает путь из параметра `file`. Выход за каталог квитанций позволяет прочитать `flag.txt`.

## Решение

### 1. Найти обработчик файлов

На главной странице форма и ссылки квитанций используют `GET /view?file=…`. Это даёт конкретную точку проверки обработки пути.

### 2. Выйти за базовый каталог

Запрос `/view?file=..%2F..%2Fflag.txt` возвращает HTTP 200 и содержимое файла. Две последовательности `../` выводят путь из каталога квитанций.
