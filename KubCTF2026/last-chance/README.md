# [ Last chance ]

**Турнир:** KubCTF · **Категория:** forensics

**Статус:** Решено.

## Кратко

Служебные данные PDF содержат разрезанный QR, ASCII-маркер и AES-CBC ciphertext. Их нужно связать, а не интерпретировать как настоящую подпись или JBIG2.

## Решение

### 1. Собрать соль и IV

Декодировать PNG из `QR_PART1` и `QR_PART2`, поставить вертикально. Полученный QR 145×145 — version 2, модуль 5 px, quiet zone 2; его текст — `salt=7f3c92a1b4e5`. Hex-декодирование потока объекта 100 раскрывает буквальный маркер `a1b2c3d4e5f67890`.

### 2. Расшифровать объект 102

Вычислить `SHA256(b"7f3c92a1b4e5" + b"a1b2c3d4e5f67890")`. Ключ: `abe8776b44fe11b45796f16e3dc7ca763200c402002919bc4de386c97b9f1c8d`. IV — 16 ASCII-байт маркера, а не 8 байт после hex-декодирования. AES-256-CBC расшифровывает все 64 байта объекта 102; убрать семь байтов 0x07. Независимая проверка подтвердила обратное шифрование.
