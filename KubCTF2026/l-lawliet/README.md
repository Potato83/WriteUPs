# L. Lawliet

**Турнир:** KubCTF · **Категория:** crypto

**Статус:** Решено.

## Кратко

Каждый блок — subset sum на 64 публичных весах. Решётка с дополнительной координатой центра и проверкой точной суммы восстанавливает семь блоков.

## Решение

### 1. Построить подходящее вложение

Использовать строки `(2e_i, 32*w_i, 0)` и центральную строку `(1,…,1,32*c,1)`. Для правильного подмножества короткий вектор имеет вид `(2x−1,0,−1)`. Последняя координата отличает нужный косет от коротких однородных зависимостей.

### 2. Сократить решётку и проверить все суммы

LLL и BKZ-30 с четырьмя циклами, затем строки и суммы/разности пар первых 20 строк дают пять блоков без предположений о тексте. Их ASCII-декодирование обосновывает фиксацию MSB каждого байта в ноль; это позволяет восстановить остальные два блока. Для каждого решения проверить бинарность и точное равенство `sum(x_i*w_i) == c`. Читать биты MSB-first и убрать ровно три конечных NUL.
