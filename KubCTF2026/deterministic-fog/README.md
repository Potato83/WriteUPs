# The Deterministic Fog

**Турнир:** KubCTF · **Категория:** crypto

**Статус:** Решено.

## Кратко

Шум LWE генерирует один предсказуемый LCG. Утечка старших байтов его состояний позволяет убрать шум и решить линейную систему.

## Решение

### 1. Восстановить LCG по калибровке

Даны 24 старших байта последовательных состояний 48-битного affine LCG. Представить траекторию как `x_i = a^i*x_0 + c_i mod 2^48`, построить решётку допустимых траекторий и приблизить центры наблюдаемых интервалов через LLL/Babai. Получается seed `0xb157d82a41b4`; все 24 наблюдения должны совпасть.

### 2. Убрать шум и прочитать биты

Продолжить генератор после калибровки. Вычесть 200 значений шума из публичного вектора b и решить систему ранга 40 над GF(257). Продолжить тот же sampler для ciphertext: остаточные фазы должны быть только 0 и 128. MSB-first упаковка 344 бит даёт 43 байта. Штатная `build_session` полностью воспроизводит исходный output.json.
