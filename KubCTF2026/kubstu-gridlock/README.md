# [Beginner] Gridlock

**Турнир:** KubCTF · **Категория:** web

**Статус:** Решено.

## Кратко

SQL-инъекция в поле пароля позволяет войти под `admin` и увидеть master key.

## Решение

### 1. Обойти проверку пароля

В форме входа указать username `admin`, а в password следующую строку (после `--` нужен пробел):

```sql
' OR '1'='1' -- 
```

Обычный `admin` / `admin` ранее был отвергнут. Инъекция делает условие проверки пароля истинным и комментирует остаток запроса. Исходный SQL сервера не предоставлен, поэтому точная конструкция запроса не утверждается.

### 2. Прочитать master key

После отправки формы открывается `/console`: username и роль — `admin`, уровень доступа — Full. Поле Master key содержит строку ниже. Результат повторён в отдельной вкладке.

## Флаг

```text
kubstu{gr1dl0ck_4dm1n_byp4ss_a59c3848}
```
