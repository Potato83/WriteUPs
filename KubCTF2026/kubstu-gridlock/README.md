# [Beginner] Gridlock

**Турнир:** KubCTF · **Категория:** web

**Статус:** Решено.

## Кратко

SQL-инъекция в поле пароля позволяет войти под `admin` и увидеть master key.

## Решение

### 1. Обойти проверку пароля

В форме входа указать username `admin`, а в password следующую строку (после `--` нужен пробел):

```sql
' OR '1'='1' -- 
```

Инъекция делает условие проверки пароля истинным и комментирует остаток запроса. Исходный SQL сервера не предоставлен, поэтому точную конструкцию запроса восстановить нельзя.

### 2. Прочитать master key

После отправки формы открывается `/console`: username и роль — `admin`, уровень доступа — Full. В поле Master key появляется искомое значение.
