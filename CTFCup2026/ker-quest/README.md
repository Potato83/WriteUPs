# ker quest

**Турнир:** Кубок CTF России 2026 · **Категория:** misc

**Статус:** Флаг восстановлен.

## Кратко

Цепочка вложенных архивов объединяет восстановление PNG, реверс бинарников, анализ аудио и трафика, OSINT и деобфускацию JavaScript.

## Решение

Каждый найденный пароль открывает следующий архив:

| Этап | Наблюдение | Пароль следующего архива |
|---|---|---|
| Год первого CTF | Перебор годов для AES ZIP через `7z t` | `2015` |
| PNG | Повреждена высота IHDR; перебор по сохранённому CRC даёт 1497 вместо 1152. В нижней части появляется надпись. | `myfirstsolvedforensicstask2016` |
| Пазл | Частичная сборка повёрнутых фрагментов раскрывает фразу. | `takearesttraveller` |
| MIPS crackme | Проверка 22 байтов сводится к системе линейных уравнений; полученный ключ проверен подстановкой. | `easyreverseforeveryone` |
| WAV | После исправления заголовка запись произносит пароль фонетическим алфавитом. | `th3r34l0n3p4ssw0rd1337` |
| Две картинки Base64 | Распознать сетку символов и декодировать изображения последовательно. В извлечённом ELF пароль лежит в `.rodata`. | `ohnicetoseeyouin2036year` |
| PCAP | Каждый UDP-пакет содержит ZIP. Уникальный архив в пакете 1337 открывается паролем `1337` и содержит следующий пароль. | `glinomesieforever` |
| Фото из окна | Вывеска Ebihara Store помогает определить Super Hotel Premier Akihabara. | `superhotelpremierakihabara` |
| JavaScript | Пять функций проверяют 20 символов через XOR; восстановленную строку принимает исходная проверка. | `junkjunkjunkjunkcode` |

Например, восстановление высоты PNG по исходному CRC:

```python
import struct
import zlib
from pathlib import Path

b = bytearray(Path('task.png').read_bytes())
wanted = struct.unpack('>I', b[29:33])[0]
for height in range(1, 5001):
    struct.pack_into('>I', b, 20, height)
    if zlib.crc32(b[12:29]) == wanted:
        print('Высота:', height)
        Path('task-restored.png').write_bytes(b)
        break
```

В финальном архиве строка закодирована ROT13. Примените ROT13, чтобы получить ответ. Каждый пароль проверяется попыткой открыть следующий архив; частично собранной фразы из пазла хватило для перехода дальше.
