# Ровный робот — Flygammon

**Турнир:** Кубок CTF России 2026 · **Категория:** misc

**Статус:** Разбор; получение флага не подтверждено.

## Кратко

Секрет генератора кубиков восстанавливается из публичного ключа; это позволяет заранее моделировать партии и отбирать выигрышные.

## Решение

В `VRF.sol` оракул вычисляет `u = keccak256("flygammon-vrf-u" || gameId || turn) mod P`, затем `y = u^s mod P` и получает кубики из `y`. Публичный ключ — `H = G^s mod P`. Контракт проверяет доказательство корректности оракула, но подделывать его не требуется: в исследованном инстансе `P − 1` раскладывается на небольшие простые множители.

Для каждого множителя `q` вычисляем `g = G^((P−1)/q) mod P` и `h = H^((P−1)/q) mod P`. Дискретный логарифм `log_g(h)` даёт `s mod q`; остатки объединяются китайской теоремой об остатках. Результат проверяется равенством `pow(G, s, P) == H`.

До `commit()` можно бесплатно вызвать `skip()`, а ходы оракула детерминированы его моделью. Зная секрет и веса модели, можно симулировать партии заранее: пропускать прогнозируемые поражения и начинать выигрышные. Цель — 15 побед подряд, после чего флаг доступен через `/flag`.

В исходных заметках описан отдельный решатель и формат весов `model.fly`, но его файлы в имеющихся материалах отсутствуют. Восстановление секрета проверено на одном инстансе; прохождение серии и получение флага доступными материалами не подтверждены. Поэтому этот разбор описывает способ решения, а не воспроизводит полное прохождение.
