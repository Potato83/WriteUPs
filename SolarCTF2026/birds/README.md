# Birds

**Турнир:** SolarCTF · **Категория:** osint

**Статус:** Не решено.

## Что известно

Птицы на фото — повторяющееся японское ограждение Sunpole Picolino. Узнать изделие оказалось проще, чем установить конкретную точку камеры.

## Ход анализа

В JPEG нет GPS. По официальной карте разобраны 1878 установок и около 2901 фотографий. Совпадения только по модели птиц недостаточны: требуются тот же бордюр, изгородь, дерево и горный фон.

## Результат и ограничения

Точная позиция с допуском ±3 м не установлена. Несколько ранее предложенных парков отвергнуты при сравнении. Публиковать их координаты как ответ нельзя.
