# LockPick

**Турнир:** SolarCTF · **Категория:** reverse

**Статус:** Решено.

## Кратко

Конфигурация iCE40 скрывает аппаратный замок. Совместное решение двух логических условий и последовательная симуляция восстанавливают кандидат флага.

## Решение

### 1. Восстановить netlist

Преамбула `FF 00 00 FF 7E AA 99 7E` соответствует iCE40. Использованы [Project IceStorm](https://github.com/YosysHQ/icestorm/tree/b77a2d5b84d88cdab96b218c21330bd609af4546): `icepack -u` принял bitstream и определил device 1k, затем `icebox_vlog` восстановил Verilog. Для анализа bitstream преобразован в netlist средствами IceStorm.

### 2. Решить оба условия и смоделировать выход

Условия `n70` и `n141` должны выполняться одновременно. Только n70 даёт несколько решений; вместе получается уникальный набор 32 физических входов. Добавление запрета найденной модели даёт unsat. Симулятор моделирует 105 flip-flops и синхронную SB_RAM40_4K READ_MODE1. Reset высок на циклах 0–1, trigger — 5–7; данные захватываются после фронта, если до фронта n110 высок.

### 3. Прочитать 29 байт

Порядок выходных битов 0…7: `io_5_17_0`, `io_3_0_0`, `io_4_0_0`, `io_0_3_0`, `io_4_0_1`, `io_2_0_0`, `io_0_2_0`, `io_0_2_1`. Он подобран по узнаваемому префиксу события; unlock io_2_0_1 устанавливается. Кандидат воспроизводится локально; независимая проверка и принятие платформой не подтверждены.
