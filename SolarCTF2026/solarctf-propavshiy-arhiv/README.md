# Пропавший архив

**Турнир:** SolarCTF · **Категория:** crypto

**Статус:** Решено.

## Кратко

У каждого RSA-модуля раскрыты 518 старших бит одного множителя. Центрированная атака Coppersmith восстанавливает три части флага; первая определяется известным форматом.

## Решение

### 1. Построить малый корень

Для 1024-битного множителя `p = h*2^506 + x`, где h известен. Сузить интервал большего нечётного множителя: либо использовать данный префикс, либо интервал для `n/p`. Выбрать нечётный центр C и представить множитель как `C+2y`. Полином `f(y)=y+C*2^(-1) mod n` имеет малый корень по неизвестному делителю n.

### 2. Восстановить три суффиксные доли

Решётка из `n^(m−i)*(y+c)^i` и `y^j*(y+c)^m`, с масштабом X^k по столбцам, сокращается LLL heuristic/dpe, delta .75, EARLY_RED. Успешные параметры для записей 1,2,3: (36,37), (35,36), (36,37). После gcd полиномов проверить множители, простоту, известный префикс, RSA decryption и re-encryption. Последние восемь байт plaintext: `{31a1e6f`, `428f7b19`, `6ac1fe4}`.

### 3. Собрать ответ с явной границей доказательства

Генератор делит 32-байтный флаг на четыре доли по восемь байт. Пользователь сообщил формат `SOLARCTF{`, поэтому первая доля — `SOLARCTF`. Запись 0 не факторизована: первые восемь байт выводятся из формата, а не расшифрованы RSA. Независимая проверка подтвердила записи 1–3, пользователь подтвердил полный кандидат.
