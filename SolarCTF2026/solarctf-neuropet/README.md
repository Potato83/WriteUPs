# Нейропитомец

**Турнир:** SolarCTF · **Категория:** forensics

**Статус:** Решено.

## Кратко

В Android backup спрятаны дополнительный DEX и байткод VM. Программа devroom выдаёт четыре сегмента, из которых собирается полный флаг.

## Решение

### 1. Найти настоящий исполняемый ресурс

Backup имеет заголовок `ANDROID BACKUP\n1\n1\nnone\n`, после него zlib-поток TAR. APK содержит brain.bin, skin.dat, weights.bin и libneurocore.so. weights.bin относится к анимации; VM исполняет brain.bin. skin.dat — XOR/LCG-зашифрованный DEX со скрытой LabActivity: пять быстрых нажатий на бренд в About открывают лабораторию.

### 2. Разобрать devroom

brain.bin — NRBC v1 с программами mood и devroom. Записи снимаются LCG-потоком по seed записи; opcode декодируется как `(-73*byte − 75) mod 256`. Начальный стек devroom содержит 0. У SHL/SHR верхний элемент — значение, следующий — число сдвигов. Это важно для точной эмуляции.

### 3. Склеить все EMIT

За 525 инструкций получаются записи типов 1…4: `SOLARCTF{F`, `R1d0Mp_Sc4`, `n_p4G3s_i`, `n_GamEEE}`. query(0) возвращает только первый канал с `NEUROC1!`, поэтому одного дампа query0 недостаточно. Конкатенация всех четырёх полезных нагрузок даёт строку ниже. Есть две локальные реализации VM, но отдельная независимая проверка отсутствует.

## Флаг

```text
SOLARCTF{FR1d0Mp_Sc4n_p4G3s_in_GamEEE}
```
