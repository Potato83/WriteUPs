# Вентилятор303

**Турнир:** SolarCTF · **Категория:** forensics

**Статус:** Решено.

## Кратко

WAV скрывает FSK-кассету с Z80-программой. Внутри — LCG, XOR и перестановка символов флага.

## Решение

### 1. Декодировать кассету

С 15-й секунды идёт FSK 1200/2400 Гц, 1200 baud, 8N1, биты LSB-first. После 240 байт U находится обёртка `VENTILATOR-303 TAPE v1`, FORMAT ZXTAP, LEN 16659, CSUM 88D9. CRC-16/CCITT с init 0xffff совпадает; четыре TAP-блока проходят XOR checksum.

### 2. Воспроизвести Z80-преобразование

BASIC загружает код по 0x8000. Подпрограмма 0x8202 обновляет `state = state*0x41c64e6d + 12345 mod 2^32`. Seed по 0x83d4 — 0x19870419. Подпрограмма 0x82a2 снимает XOR с 43 байт по 0x8403, используя `(state >> 16) & 255`, и расставляет символы по таблице с 0x83d8. Независимый zero-crossing decoder и интерпретатор Z80 подтвердили все 43 состояния и буквальные дефисы флага.
